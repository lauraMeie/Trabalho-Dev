## Fluxo completo

1. **Entrar** no app (ou criar a conta de professor).
2. Cadastrar as **turmas** e os **alunos**.
3. Cadastrar as **questões** no banco.
4. **Criar a prova**, gerar o PDF e imprimir as questões e a folha de respostas de cada aluno.
5. Depois da aplicação, **corrigir** cada folha pela câmera.
6. Acompanhar os **relatórios** e exportar as notas para o Excel.

## Para quem for escrever uma seção

- Crie um arquivo `.md` próprio nesta pasta (um por módulo, para ninguém editar o mesmo arquivo ao mesmo tempo) e troque o *(em construção)* da tabela pelo link.
- Coloque os prints em `img/<modulo>/`, numerados na ordem dos passos (ex.: `img/turmas/01-lista-de-turmas.png`).
- Siga o modelo de `correcao-e-relatorios.md`: o que o módulo faz, passo a passo numerado com prints e uma tabela de problemas comuns.
